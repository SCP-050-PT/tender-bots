ЗАДАЧА: Извлеки параметры для расчёта ОПР (оценка профессиональных рисков) с географией.

ПРИОРИТЕТ КОЛИЧЕСТВА (opr_positions):
1. Явные фразы: «N должностей», «N рабочих мест», «N позиций», «N карт рисков», «количество = N» в таблице НМЦК/ТЗ.
2. Сумма по столбцу «Кол-во» / «Количество» в таблицах обоснования НМЦК.
3. Если в тексте есть маркер парсера «=== ИЗВЛЕЧЕНО ИЗ ТАБЛИЦЫ: Количество = N ===» — используй N.
4. НЕ путай с ценой, НМЦК, процентами, номерами пунктов (1.2.3).
5. Диапазон здравого смысла: обычно 5–800 должностей. Если видишь 1 при НМЦК > 100 тыс. — ищи другое число в таблице.
6. Если точного числа нет — поставь null (fallback посчитает по НМЦК), НЕ error.

Также:
- opr_persons: работники; если нет — = opr_positions или null
- addresses_count / cities_count: по списку объектов/филиалов в ТЗ (не 1 по умолчанию при нескольких адресах)
- regions_count
