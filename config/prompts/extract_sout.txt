- rm_total: число РМ (ИТОГО/ВСЕГО/таблицы). Нет цифры — оценка по объёму, is_estimated=true.
- addresses_count, cities_count, regions_count: по списку объектов; нет списка → 1.
- has_iii: true только ионизирующие/рентген/радиация.
- seasonality: true для ЯНАО, ХМАО, Мурманск, Архангельск, Коми, Якутия, Камчатка, Магадан.
